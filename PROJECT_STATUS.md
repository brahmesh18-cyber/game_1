# ECHOBOUND Prototype Status

This is a **starter repository**, not the finished game.

The current implementation establishes the modular architecture and the core Echo recording/playback foundation.

Next recommended milestone:
1. Create a Unity scene.
2. Connect the Player and Echo prefab.
3. Test R/P recording and playback.
4. Add interaction-event replay.
5. Add real third-person combat.
6. Add the first boss prototype.

The design specification explicitly recommends beginning with the single-room prototype.
